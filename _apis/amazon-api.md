RESTful API for extracting product data, pricing, reviews, ratings, and seller information from Amazon marketplaces worldwide. ## API Features

- **Simple Integration**: RESTful API with JSON responses, easy to integrate
- **High Reliability**: 99.7% success rate across 2.3M+ ASIN extractions, automatic retry logic, error handling
- **Real-time Data**: Get product data updates as they happen on Amazon
- **Scalable**: Handle millions of requests per day, auto-scaling infrastructure
- **Anti-Bot Bypass**: Automatically handles CAPTCHAs, IP rotation, rotating proxies, and "Dog" page errors

## What You Can Extract

- **Product Data**: Titles, descriptions, images, ASINs, categories, specifications
- **Pricing**: Current prices, list prices, discounts, deals, price history
- **Reviews & Ratings**: Customer reviews, ratings, Q&A, review trends
- **Seller Information**: Seller names, ratings, shipping options, fulfillment methods
- **Inventory**: Stock status, availability, shipping times, delivery options
- **Sales Data**: Best seller rank, sales velocity, trending products

## API Endpoints

```
GET /api/v1/amazon/product
GET /api/v1/amazon/reviews
GET /api/v1/amazon/sellers
GET /api/v1/amazon/search
```
