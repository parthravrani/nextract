# Etsy API

RESTful API for extracting comprehensive product data, pricing, reviews, ratings, and seller information from Etsy marketplace.

## API Features

- **Simple Integration**: RESTful API with JSON responses, easy to integrate
- **High Reliability**: High uptime commitment, automatic retry logic, error handling
- **Real-time Data**: Get product data updates as they happen on Etsy
- **Scalable**: Handle millions of requests per day, auto-scaling infrastructure
- **Anti-Bot Bypass**: Automatically handles CAPTCHAs, IP rotation, and anti-bot measures

## What You Can Extract

- **Product Data**: Titles, descriptions, images, tags, categories, materials
- **Pricing**: Current prices, shipping costs, currency conversion, price history
- **Reviews & Ratings**: Customer reviews, ratings, shop reviews, review trends
- **Seller Information**: Shop names, seller ratings, shop policies, shipping options
- **Inventory**: Stock status, quantity available, variations, customization options
- **Sales Data**: Best sellers, trending products, sales velocity, shop performance

## API Endpoints

```
GET /api/v1/etsy/product
GET /api/v1/etsy/reviews
GET /api/v1/etsy/shops
GET /api/v1/etsy/search
```
