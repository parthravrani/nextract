# Swiggy API

RESTful API for extracting comprehensive food delivery data including restaurant menus, prices, reviews, ratings, and delivery information from Swiggy platform.

## API Features

- **Simple Integration**: RESTful API with JSON responses, easy to integrate
- **High Reliability**: High uptime commitment, automatic retry logic, error handling
- **Real-time Data**: Get restaurant data updates as they happen on Swiggy
- **Scalable**: Handle millions of requests per day, auto-scaling infrastructure
- **Anti-Bot Bypass**: Automatically handles CAPTCHAs, IP rotation, and anti-bot measures

## What You Can Extract

- **Restaurant Data**: Restaurant names, addresses, cuisines, ratings, delivery times
- **Menu Data**: Dishes, descriptions, prices, categories, dietary information, allergens
- **Reviews & Ratings**: Customer reviews, ratings, photos, sentiment analysis
- **Delivery Data**: Delivery fees, minimum orders, delivery time estimates, coverage areas
- **Promotions**: Active promotions, discounts, deals, offers
- **Operational Data**: Restaurant hours, availability, peak times

## API Endpoints

```
GET /api/v1/swiggy/restaurants
GET /api/v1/swiggy/menus
GET /api/v1/swiggy/reviews
GET /api/v1/swiggy/search
```
