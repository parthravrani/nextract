## Best Buy API

RESTful API for extracting comprehensive electronics product data, pricing, reviews, ratings, and specifications from Best Buy.

## API Features

- **Simple Integration**: RESTful API with JSON responses, easy to integrate
- **High Reliability**: High uptime commitment, automatic retry logic, error handling
- **Real-time Data**: Get product data updates as they happen on Best Buy
- **Scalable**: Handle millions of requests per day, auto-scaling infrastructure
- **Anti-Bot Bypass**: Automatically handles CAPTCHAs, IP rotation, and anti-bot measures

## What You Can Extract

- **Product Data**: Titles, descriptions, images, SKUs, categories, specifications, tech specs
- **Pricing**: Current prices, sale prices, clearance prices, price history, trade-in values
- **Reviews & Ratings**: Customer reviews, ratings, Q&A, expert reviews, review trends
- **Inventory**: Stock status, availability, pickup options, shipping information
- **Store Data**: Store availability, pickup locations, store hours, Geek Squad services
- **Sales Data**: Best sellers, trending products, sales velocity, deals

## API Endpoints

```
GET /api/v1/bestbuy/product
GET /api/v1/bestbuy/reviews
GET /api/v1/bestbuy/search
GET /api/v1/bestbuy/inventory
```
