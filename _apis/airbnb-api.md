# Airbnb API

RESTful API for extracting comprehensive property listings, pricing, availability, reviews, and booking information from Airbnb.

## API Features

- **Simple Integration**: RESTful API with JSON responses, easy to integrate
- **High Reliability**: High uptime commitment, automatic retry logic, error handling
- **Real-time Data**: Get property data updates as they happen on Airbnb
- **Scalable**: Handle millions of requests per day, auto-scaling infrastructure
- **Anti-Bot Bypass**: Automatically handles CAPTCHAs, IP rotation, and anti-bot measures

## What You Can Extract

- **Property Listings**: Titles, descriptions, images, amenities, property type, capacity
- **Pricing**: Nightly rates, cleaning fees, service fees, seasonal pricing, discounts
- **Availability**: Booking calendars, availability status, minimum stay requirements
- **Reviews & Ratings**: Guest reviews, ratings, host responses, review trends
- **Host Information**: Host profiles, response rates, superhost status, verification
- **Location Data**: Address, coordinates, neighborhood information, nearby attractions

## API Endpoints

```
GET /api/v1/airbnb/listings
GET /api/v1/airbnb/reviews
GET /api/v1/airbnb/availability
GET /api/v1/airbnb/search
```
