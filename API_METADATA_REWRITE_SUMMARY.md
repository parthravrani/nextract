## Changes Applied

### Rule #1: Titles Now Front-Loaded & Benefit-Driven
- ❌ **Old Format:** `Nextract | Platform | Keywords`
- ✅ **New Format:** `Platform API: Benefit (Nextract)`
- Brand moved to end (or removed if length tight)
- Benefit comes first

### Rule #2: Descriptions Pass "Specifics Test"
- Removed buzzwords: "comprehensive," "seamless," "robust"
- Added specific numbers and data points
- Included pain point solutions
- Max 155 characters

### Rule #3: Eliminated "Pipe Stuffing"
- No more `|` separators in titles
- Natural, human-readable format
