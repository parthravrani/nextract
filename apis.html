Endpoint

Product lookup

GET /product

Returns live product data for a single ASIN or SKU: title, images, pricing, Buy Box winner, BSR, ratings, availability, and more.

Parameters

asin requiredASIN, product ID, or URL slug depending on the platform.
platform requiredPlatform identifier: amazon_in, amazon_us, flipkart, walmart.
fields optionalComma-separated list of fields to return. Defaults to all. E.g. title,price,buy_box.
marketplace optionalAmazon marketplace code when needed — e.g. IN, US.

Response

{ "asin": "B09G9HD6PD", "platform": "amazon_in", "title": "boAt Rockerz 450 Pro On-Ear Bluetooth Headphones", "brand": "boAt", "price": { "current": 1299, "mrp": 2999, "discount_pct": 56.7, "currency": "INR" }, "buy_box": { "winner": "Appario Retail Pvt Ltd", "is_amazon": false, "fulfilment": "FBA" }, "bsr": [ { "rank": 3, "category": "Electronics" }, { "rank": 1, "category": "Bluetooth Headphones" } ], "rating": 4.2, "review_count": 14832, "in_stock": true, "fetched_at": "2026-06-16T07:12:44Z" }

Endpoint

Bulk jobs

POST /jobs

Submit a list of ASINs or SKUs for asynchronous processing. Returns a job_id you can poll. Results are also pushed to your webhook URL when ready.

Body (JSON)

items requiredArray of objects with id and platform. Max 10,000 per job.
fields optionalFields to return per item. Defaults to all.
webhook_url optionalHTTPS URL. We POST results here when the job completes.
notify_email optionalEmail to notify when results are ready to download.

Request body

{ "items": [ { "id": "B09G9HD6PD", "platform": "amazon_in" }, { "id": "B0CHX1W1XY", "platform": "amazon_in" }, { "id": "SKU_92841", "platform": "flipkart" } ], "fields": ["title", "price", "buy_box", "in_stock"], "webhook_url": "https://your-app.com/hooks/nextract" } ──── Response ──── { "job_id": "job_8f2k9p3x", "status": "queued", "item_count": 3, "estimated_seconds": 45, "results_url": "https://api.nextract.dev/v1/jobs/job_8f2k9p3x" }

Endpoint

Keyword ranks

GET /ranks

Returns organic and sponsored rank positions for a product on a given keyword, with historical data available via from and to date range params.

Parameters

asin requiredASIN or product identifier.
keyword requiredSearch term to track rank on.
platform requiredamazon_in, amazon_us, or flipkart.
from / to optionalISO 8601 date range for historical ranks.

Response

{ "asin": "B09G9HD6PD", "keyword": "wireless earbuds under 2000", "platform": "amazon_in", "organic_rank": 4, "sponsored_rank": null, "page": 1, "history": [ { "date": "2026-06-15", "organic": 6, "sponsored": 2 }, { "date": "2026-06-16", "organic": 4, "sponsored": null } ], "fetched_at": "2026-06-16T07:14:02Z" }
