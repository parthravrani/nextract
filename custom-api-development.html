Core API endpoints

What you can pull from the Nextract API.

GET /product
Product data
Price, title, stock, rating, images, description, category, seller — for any ASIN or URL.
GET /ranks
Search rankings
Position in search results for a keyword and platform. Organic vs sponsored split included.
POST /jobs
Batch extraction
Queue large batch jobs for category-level or catalogue-wide extraction with webhook delivery on completion.
GET /availability
Stock & availability
In-stock boolean, seller-level stock, and Buy Box eligibility on Amazon and other marketplaces.
